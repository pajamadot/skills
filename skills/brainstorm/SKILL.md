# /brainstorm — Guided Game Ideation

Generate game concepts using structured ideation methods.

## Methods (pick one or combine)

**1. Verb-First Design**
Start with a core verb: jump, shoot, build, connect, grow, flee, solve...
Then ask: What if [verb] + [unexpected context]?
- "What if you JUMPED through dreams?"
- "What if you BUILT with time?"

**2. MDA Backward**
Start with the feeling: tension, wonder, mastery, humor, nostalgia...
Then ask: What dynamics create that feeling?
Then: What mechanics produce those dynamics?

**3. Constraint-Based**
Pick 2-3 constraints and design within them:
- "One button only"
- "No enemies"
- "Screen never scrolls"
- "Game lasts exactly 60 seconds"

**4. Mashup**
Combine two existing games or genres:
- "Tetris meets tower defense"
- "Flappy Bird but you're the obstacle"

## Process

1. Ask: "What mood or feeling are you going for?"
2. Generate 3-5 concepts using the methods above
3. For each, give: one-line pitch, core mechanic, why it's fun
4. User picks their favorite
5. Expand into a full game concept using the template
6. Suggest running `/design-system` to create the GDD
