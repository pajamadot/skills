# Pajama Game Studio — Skills

Skill packs for AI agents building games. Install in Claude Code.

## Install

Copy any skill `.md` file to your project:
```
.claude/skills/skill-name.md
```

Or reference via MCP:
```json
{ "mcpServers": { "pajama-studio": { "command": "npx", "args": ["@pajamadot/mcp-server"] } } }
```
